# RSH Finalization Roadmap

Этот документ фиксирует порядок доведения RSH до публичного production-ready состояния. Он нужен, чтобы не распыляться и закрывать блоки в правильной последовательности.

## Статус проекта сейчас

Уже реализовано:

- базовая архитектура `Next.js + Prisma + service layer`
- публичная витрина: главная, каталог, карточка товара
- регистрация, вход, профиль
- избранное и корзина
- базовая административная панель
- юридические страницы заведены в структуре проекта
- 2D Lab работает в базовом режиме
- тесты, CI и release-gate присутствуют

Еще не доведено до production-ready:

- деплой и интеграции внешних сервисов
- финальная полировка 2D редактора
- реальный платежный прод-контур
- мониторинг, бэкапы и post-deploy smoke

## Приоритетный порядок

### Этап 1. Deployment Foundation

Цель: получить стабильный production build и готовую инфраструктуру.

Нужно сделать:

- смержить `codex/rsh-deploy-readiness`
- подключить Vercel
- подключить Neon Postgres
- подключить Upstash Redis
- подключить UploadThing
- подключить Stripe
- заполнить production env
- настроить домен
- проверить `Secure` / `HttpOnly` / `SameSite` cookies
- настроить production migration flow

Критерий готовности:

- `npm run build` проходит на production env
- preview deploy поднимается без ошибок
- production deploy проходит без ручных костылей

### Этап 2. 2D Редактор

Цель: сделать кастомайзер реально usable для демонстрации и публичной работы.

Нужно сделать:

- выровнять шаблоны футболки, худи и шорт
- проверить front/back режимы
- убрать лишние сетки, подписи и визуальный мусор
- расширить printable zones
- проверить recolor шаблона
- проверить загрузку фото с компьютера
- проверить resize / rotate / move
- довести работу слоев
- добавить undo / redo
- проверить сохранение дизайна
- проверить добавление кастомной вещи в корзину
- сохранять `fabric JSON + preview`
- проверить mobile UX

Критерий готовности:

- пользователь может собрать вещь без поломок UI
- дизайн сохраняется и возвращается
- кастомный товар доходит до корзины и checkout

### Этап 3. Каталог и карточки товаров

Цель: привести витрину к состоянию полноценного магазина.

Нужно сделать:

- заполнить реальные товары
- добавить по 3 изображения на товар
- добавить описание, бренд, размер, цвет, материал
- уточнить остатки / наличие
- проверить фильтры брендов, цены и размеров
- довести SEO карточек товара

Критерий готовности:

- каталог выглядит полноценным
- карточка товара содержит весь нужный контент
- фильтры работают предсказуемо

### Этап 4. Корзина, Checkout и заказы

Цель: закрыть коммерческий сценарий от добавления товара до появления заказа в профиле.

Нужно сделать:

- проверить, что гостевая корзина не пропадает после входа
- проверить merge корзины после логина
- довести checkout flow
- подключить реальный Stripe Checkout
- проверить webhook-подтверждение заказа
- проверить появление заказа в профиле после оплаты

Критерий готовности:

- покупатель может оформить заказ
- заказ фиксируется в базе и виден в профиле

### Этап 5. Кабинет пользователя и админка

Цель: закрыть рабочие сценарии пользователя и администратора.

Нужно сделать:

- профиль
- история заказов
- статусы заказов
- избранное
- безопасность и управление сессиями
- управление товарами
- управление заказами
- управление пользователями
- логи действий
- контент и настройки
- экспорт данных
- проверка ролей `ADMIN / USER`

Критерий готовности:

- пользовательский кабинет полезен и понятен
- админка закрывает операционные сценарии магазина

### Этап 6. Security / Monitoring / Backups

Цель: сделать публичный запуск безопасным и управляемым.

Нужно сделать:

- проверить `Secure HttpOnly cookies`
- проверить CSRF
- проверить rate limiting
- проверить RBAC
- проверить validation на всех границах
- проверить upload validation
- проверить Stripe webhook signature
- проверить отсутствие auth token в `localStorage`
- проверить env перед deploy
- подключить Sentry или аналог
- настроить журнал ошибок
- настроить бэкапы базы
- проверить Stripe events
- проверить upload errors

Критерий готовности:

- система мониторится
- ошибки не теряются
- есть план восстановления

### Этап 7. Final Smoke Test

Цель: пройти полный сценарий перед публичным запуском.

Проверить:

- регистрация
- логин
- каталог
- фильтры
- карточка товара
- корзина
- checkout
- оплата
- заказ в профиле
- 2D редактор
- кастомная вещь в корзине
- админка
- мобильная версия

## Что делаешь ты

- загружаешь реальные фото товаров
