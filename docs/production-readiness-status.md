# RSH Production Readiness Status

## Текущее состояние

На текущий момент проект находится в состоянии **feature-complete beta**:

- основная витрина магазина работает;
- каталог, карточки товаров, избранное, корзина, профиль и админ-панель уже реализованы;
- 2D Lab работает как отдельный модуль кастомизации базовой линейки;
- строгая типизация и `npm run typecheck` проходят успешно;
- локальная разработка запускается стабильно;
- production build блокируется не кодом приложения, а отсутствием реальных production-переменных окружения и внешних сервисов.

Это означает, что фундамент уже собран, но до **100% production-ready публичного запуска** нужно закрыть интеграционные, эксплуатационные и UX-доработки.

## Текущий production-блокер

Сейчас главный блокер production build — **не сломанный код**, а отсутствие реальных production env variables и реальных сервисов.

Система уже требует:

- `APP_URL` c реальным `https` доменом
- корректный `COOKIE_DOMAIN`
- разные `JWT_ACCESS_SECRET` и `JWT_REFRESH_SECRET`
- `UPLOADTHING_TOKEN`
- `UPLOADTHING_APP_ID`
- реальный `STRIPE_SECRET_KEY`, начинающийся с `sk_live_`

Пока этого нет, production build и публичный деплой не должны считаться завершёнными.
